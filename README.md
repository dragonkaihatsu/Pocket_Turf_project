# Pocket TURF project

競馬の「予想」と「育成ゲーム」を扱うリポジトリ。

| パス | 内容 |
|---|---|
| `CLAUDE.md` | JRA中央競馬・地方競馬の重賞を100点満点でスコアリングし、印（◎○▲△注）と買い目プランをHTML形式で出力するためのタスク仕様書 |
| `data/` | 出走馬データ・過去データのCSVを置くディレクトリ |
| `game/pocket-turf.html` | **ポケットターフ** — DS風の上下2画面で遊ぶ競馬育成ゲーム（単一HTMLファイル） |

パッケージマネージャもビルド設定も持たない。ビルド・lint・テストのコマンドは存在しない。

## ポケットターフ

`game/pocket-turf.html` をブラウザで開けば動く。外部依存はGoogle Fontsのみ。

- 上画面にレースと厩舎、下画面にタッチ操作という2画面構成。スマホの縦持ちを前提にしている
- 1年50週・3歳から5歳までの150週で愛馬を育てる。調教・休養・出走・観戦・アルバイトから毎週ひとつ選ぶ
- レースは8頭立て。脚質・ペース・適性・消耗に加え、競馬場ごとの直線距離・小回り・ゴール前の坂が結果を左右する。走破時計は実際のJRAに合わせてある
- 出走前に単勝・複勝をメダルで購入する。愛馬を出走させず馬券だけ買う観戦モードもある
- レース中の操作はペース管理（1〜5）のひとつ。**4と5は残り400mに入るまで押せない**ので、道中は1〜3で脚をためる位置取り、最後の400mで4→5をどう使うかの勝負になる。正解は距離ごとに変わり、長い距離ほど道中を落として溜めるのが効く
- 脚質の有利不利は実際のJRA（複勝率 逃げ49.5% > 先行45.5% > 差し26.9% > 追込14.1%）に合わせて前が有利。ただし東京の長い直線や長距離では差し・追込が届く
- 先頭は風を正面から受けるので、離せるのはよくて10馬身。2馬身以内で競りかけられると消耗が跳ね上がり、逃げ切れるか競り潰されるかが決まる
- 調教にはメダルが要る。疲労が25を切っているあいだは伸びが3倍になるので、休ませてから鍛えるのが基本になる。疲労が75を超えるとドクターストップで調教も出走もできない
- 同じ調教を積むほど施設のレベルが上がり、伸びが加速する（Lv5で1.85倍）。成長型は無く、どこまで届くかは鍛え方しだい
- 相手も年齢とともに強くなる。3歳は苦しく、5歳で突き放す——ただし強くなるのはカレンダーであって、あなたの能力に合わせて相手が強くなることはない
- 馬券の払戻が累計1万枚たまるごとに、黄緑に光る「スペシャル調教」が1回だけひらく。500メダルでランダムな能力が5〜10上がる
- 資金繰りは楽ではない。尽きたらアルバイトで立て直す。ライブ配信（2週）・トラックの配達・サイン会（ファン数の10%）・ボートレース場営業（0〜5,000枚）の4つで、消費する週も振れ幅も違う
- 貯めたメダルは売店でコーヒー・ビール・シャンパンに換えて能力を伸ばせる。春のさくらもち・夏のかきごおり・秋の金の焼き芋・冬の熱々おでんは、その季節にしか置かず愛馬1頭につき一度だけ
- G1を2勝すると招待状が届き、四季を巡る4つのカップに挑める。どれかひとつでも勝てば、年の暮れに最強の相手が待つレジェンドカップ——ピラミッドとスフィンクスの月夜——が現れる
- 一度愛馬を引退させるとハードモードが解禁される。相手のレベルが一律+5、伸び3倍の帯は疲労15未満まで狭まり、季節限定アイテムは1周に1つだけになる（賞金は変わらない）
- セーブは自動保存に加えて、12文字のひらがな（4-4-4）の合言葉で呼び出せる

バランス調整の指針と検証方法は `CLAUDE.md` に書いてある。`window.PocketTurf` からレース物理を直接叩けるので、ヘッドレスブラウザで走破時計や脚質の分布を統計的に測れる。

## 予想システム

`data/` にCSV（`レース名_出走馬.csv`、必要に応じて `レース名_過去10年.csv`）を置き、`CLAUDE.md` の配点に従ってスコアリングから買い目プランまでを生成する。レース結果が出たら、そのフィードバックを `CLAUDE.md` の「過去の学習事項」に追記して配点を育てていく。
