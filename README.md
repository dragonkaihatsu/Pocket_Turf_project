# 競馬予想システム（100点スコアリング）

`CLAUDE.md` の仕様をコード化した、CSV入力 → 100点スコアリング → HTML出力までを
行うPython製の予想システムです。標準ライブラリのみで動作し、追加の依存パッケージは
不要です（Python 3.11+ を想定）。

## ディレクトリ構成

```
keiba/
  models.py    # CSV読み込み・データモデル（Horse, HistoryRecord）
  scoring.py   # 100点スコアリングエンジン（配点表・補正項目）
  marks.py     # 印（◎○▲△注）の割り振り
  betting.py   # 買い目プラン生成（単勝・ワイド・馬連）
  pace.py      # ペース別展開予想
  report.py    # 予想HTML（スマホ対応カード・ダークテーマ）
  feedback.py  # レース後フィードバックHTML（回収率計算）
  cli.py       # コマンドラインエントリポイント
data/          # 入力CSV（サンプルデータを同梱）
output/        # 生成されたHTMLの出力先
tests/         # ユニットテスト（サンプルデータを使った健全性チェック）
```

## 使い方

### 1. 予想を出力する

```bash
python3 -m keiba.cli predict \
  data/サンプルステークス_出走馬.csv \
  --history data/サンプルステークス_過去10年.csv \
  --race-name "サンプルステークス" --kyori 2000 --baba 良 \
  --output output/サンプルステークス.html
```

`output/サンプルステークス.html` に、CLAUDE.md の出力形式1〜4
（100点スコアリング表／スマホ対応カード／ペース別展開予想／買い目プラン）を
まとめた単一HTMLが生成されます。

### 2. レース後のフィードバックを出力する

```bash
python3 -m keiba.cli feedback \
  data/サンプルステークス_出走馬.csv \
  --history data/サンプルステークス_過去10年.csv \
  --race-name "サンプルステークス" --kyori 2000 --baba 良 \
  --results data/サンプルステークス_結果.csv \
  --payouts data/サンプルステークス_配当.csv \
  --output output/サンプルステークス_フィードバック.html
```

予測（印・スコア）と実際の着順を突き合わせ、買い目プラン（単勝100円×2点、
ワイド100円×3点、馬連100円×最大10点）の回収率を計算します。

### テストの実行

```bash
python3 -m unittest discover -s tests -v
```

## 入力CSV仕様

### 出走馬CSV（`data/レース名_出走馬.csv`）

CLAUDE.md が定義する必須カラムに加え、補正項目の計算に使う任意の拡張カラムを
サポートしています。拡張カラムが無くても動作し、その場合は補正なし（中立値）
にフォールバックします。

| カラム | 必須/任意 | 用途 |
|---|---|---|
| 馬番,枠番,馬名,性齢,斤量,騎手 | 必須 | 基本情報 |
| 前走着順,前走レース名 | 必須 | 前走内容の素点化 |
| 上がり3F | 必須 | 基礎能力の代理指標 |
| 調教評価（S/A/B/C/D または1-5） | 必須 | 調教の素点化 |
| 血統(父/母父) | 任意 | 参考表示のみ。サンプル数が少ないため過信しない |
| 乗り替わり（Y/N） | 拡張 | 騎手補正（マイナス経験値判定） |
| 前走不利（Y/N） | 拡張 | 前走不利補正 |
| 休養日数（数値） | 拡張 | 長期休養明けペナルティ（>180日） |
| 前走ハンデ戦（Y/N） | 拡張 | ハンデ戦実績の割引 |
| 脚質（逃げ/先行/差し/追込） | 拡張 | ペース別展開予想・馬場補正レイヤー |
| 道悪巧者（Y/N） | 拡張 | 馬場状態補正レイヤー（重馬場側） |
| 基礎能力評価（0-25の数値） | 拡張 | 基礎能力の手動上書き |
| 距離適性評価（0-15の数値） | 拡張 | 距離適性の手動上書き（後述） |

### 過去10年データCSV（`data/レース名_過去10年.csv`）

同一レースの過去実施分を1行1着順で記録したデータです。
`年,レース名,馬番,枠番,馬名,着順,距離,馬場状態,上がり3F`

このデータから以下を機械的に算出します:

- **枠順補正**: 枠番ごとの複勝率（着順3着以内の割合）を全体平均と比較
- **コース適性**: 出走馬と同名の馬が過去に同レースを走っていれば、その平均着順から算出
- **初コース・ぶっつけペナルティ**: 同名の出走歴が見つからない場合に付与

### 結果CSV・配当CSV（フィードバック用、`feedback`コマンドのみ）

- 結果CSV: `馬番,着順`。1〜3着だけ分かっていれば十分（`--payouts`は省略可）。
  上位3頭が確定していれば、それ以外の馬は自動的に「3着以内ではない」と
  推定してワイド・馬連の的中判定を行います（クローズドワールド推論）。
- 配当CSV: `券種,組み合わせ,配当`（組み合わせは単勝なら馬番1つ、ワイド/馬連は
  `馬番-馬番`。的中しなかった組み合わせは記載不要）。省略した場合、
  的中/ハズレの判定は着順だけで行い、金額が分からない的中チケットは
  「配当不明」、回収率は「配当データ不足のため不明」と表示します
  （0円扱いにして回収率を過小に見せることはしません）。

## スコアリングについての注記（ブラックボックス化しないための設計）

- 各馬のスコアは必ず「基礎能力・前走内容・コース適性・距離適性・調教」の5項目＋
  各補正項目の内訳（点数と根拠コメント）を保持しており、HTML出力のカードを
  タップすると内訳表が展開されます。
- **距離適性**について: CLAUDE.mdの入力仕様には「同レースの過去10年データ」のみが
  定義されており、出走馬ごとの距離別成績（他レースを含む）を横断的に参照する
  データソースは定義されていません。そのため本実装では既定で中立値
  （15点満点中8.25点）を採り、`距離適性評価`カラムでの手動評価（Claudeによる
  定性判断や別データからの入力）を推奨する設計としています。過信を避けるため、
  内訳コメントに必ずその旨を明記します。
- 血統データも同様にサンプル数が少ない前提のため、スコアには反映せず参考表示に
  留めています。
- 騎手補正の対象騎手リスト（`keiba/scoring.py` の `DEFAULT_JOCKEY_TIERS`）は
  目安の初期値です。開催・時期に応じて呼び出し側で差し替えてください。

## 過去の学習事項（CLAUDE.mdより）

- 宝塚記念フィードバックにより「馬場状態補正」「初コースペナルティ」「道悪巧者2軸」
  「高齢馬補正」を追加
- エルムSで◎テーオーパスワードが3着、1着ルクソールカフェは評価圏内だった →
  差し馬の最終直線での脚質加点を要調整（今後の配点チューニング課題）
- 新潟記念2026で、新潟大賞典2着（ハンデ戦）の実績があったバレエマスターを見送り、
  結果的に正解だった → ハンデ戦好走はスコア評価時に「本斤量・格上馬との経験値」を
  必ず個別チェックする（`前走ハンデ戦`カラムで実装済み）
- 大井12R宮益坂賞競走2026(B3)で、◎2アレグランサは1着的中したが、2着6ファーストメイト
  は基礎能力（上がり3F代理指標）が出走馬中2番目に高かったのに前走7着に引きずられ
  「注」止まりとなり、標準形式の馬連ボックス（上位5頭）の対象外だった → 前走着順
  だけで前走内容を評価すると、基礎能力の高い馬が単発の凡走で過小評価されるリスクが
  ある（配点チューニング課題・未実装）
- 同レースで3着7アスコットミヤギ（3歳）は上がり3Fが出走馬中最下位で無印だったが、
  単勝1.4倍の人気1位で、前走は黒潮盃重賞（格上）の不良馬場3着だった。結果は3着
  どまり（単勝的中ならず）で、市場人気に反して無印にした判断自体は結果的に正しかった
  → 上がり3Fがレース格・ペースに左右される点への懸念は残るが、今回はその反証には
  ならない。むしろ当日の単勝オッズとスコアを突き合わせる「オッズ整合性チェック」を
  加えると、システムの評価と市場評価のズレを毎回検証できて有用
  （オッズ入力・比較機能は現状未実装）

## 開催日ページ（Artifact共有用）

1日の複数レースを1ページにまとめた、共有用HTMLを生成できます。

```bash
python3 -m keiba.cli daily config/20260831_大井.json --output output/大井20260831.html
```

設定JSON（`config/`）に、その日のレース（レース番号・レース名・条件・発走時刻・
距離・馬場・出走馬CSV・任意で過去10年CSVと結果CSV）と、スコアリングの前提として
明記しておきたい注記を書きます。結果CSVを指定したレースには、確定着順との照合
（着順バッジ・的中/不的中タグ）が自動で付きます。

出力は `<!doctype>` などのラッパータグを含まない Artifact 向けの形式です。
そのまま Artifact として publish すると、URLで共有できるページになります。
