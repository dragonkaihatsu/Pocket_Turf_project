# ジャグラー設定判別アプリ

パチスロ「ジャグラーシリーズ」のBIG回数・REG回数・総ゲーム数から、設定1〜6それぞれの
可能性を統計的に推定する、ブラウザだけで動く単一HTMLアプリです。サーバーもビルドも
不要で、`index.html` をダブルクリックして開くだけで使えます（インターネット接続不要）。

## 使い方
1. `index.html` をブラウザ（スマホでもPCでも可）で開く
2. 人気ランキング上位3機種はワンタップの機種選択ボタンから選べる（それ以外はプルダウンから）
3. 総ゲーム数・BIG回数・REG回数を入力して「設定を判別する」を押す
4. 実戦データのまとめと、設定1〜6の推定確率（棒グラフ）が表示される
5. 気に入った結果は「この結果をログに保存する」で記録し、下の「稼働ログ・統計」で
   曜日別・イベント日別などの傾向を集計できる

データはサーバーに送信されません。すべてブラウザ内で完結し、追加・編集した確率データや
保存したログは、その端末の `localStorage` にのみ保存されます。

## 人気ランキング（2026年版・参考）
複数のスロット情報サイトの記事（設置台数・導入率・プレイヤー人気）を突き合わせた
参考ランキングです。アプリはこの上位3機種を優先的に整備しています。

1. マイジャグラーⅤ/Ⅵ
2. アイムジャグラーEX/ネオアイムジャグラーEX
3. ゴーゴージャグラー3
4. ファンキージャグラー2
5. ハッピージャグラーⅤⅢ

店舗や時期によって実際の人気・設置状況は変動するため、あくまで目安です。

## チェーン店・イベント日管理機能
対象は**東京都・自店データ（差枚等）を公開しているホール**に絞っています。

### 候補: 東京都のホール（P-WORLD / アナスロ / みんパチ掲載）
3つの外部サイトに掲載されている実在ホール**136件**を候補リストとしてアプリに内蔵しています
（2026年9月時点の抜粋・全店舗を網羅しているわけではありません）。店名・エリア（市区町村）で
絞り込み、タップ1つで下の登録フォームに読み込めます。

| 出典 | 件数 | 収録基準 | 登録時の扱い |
|---|---|---|---|
| [P-WORLD「出玉情報公開店」検索（東京都）](https://www.p-world.co.jp/_machine/kensaku.cgi?is_new_ver=1&dir=tokyo&is_dedama=1) | 50件 | 台データ公開店として公式に掲載 | 「自店データ公開」が自動でON |
| [アナスロ](https://ana-slo.com/) | 22件 | ホールごとの「データ一覧」ページの存在を個別確認 | 同上（確認できた個別URLも登録） |
| [みんパチ](https://minpachi.com/category/tokyo/) | 64件 | エリア別のホール掲載ページに実在を確認 | 口コミ・換金率・イベント情報が中心のサイトで、**台データ公開の有無はホールごとに未確認**なため「自店データ公開」はOFFのまま登録（確認できたらチェック） |

**イベント日パターンはいずれの出典にも含まれていない**ため、登録後に分かる範囲でご自身で
編集して追加してください（各ホールの公式サイト・SNS等の告知をもとに確認することを推奨します）。
候補以外の店舗も、登録フォームから自由に追加できます。

### 店舗の登録・編集
- 店舗名・エリア（市区町村・任意）・毎月のイベント日（カンマ区切りで複数指定可）・
  毎週のイベント曜日・自店データ公開の有無・データ確認先URL（任意）・備考を登録
- 登録済みの店舗は一覧の✎ボタンからいつでも編集できます（削除は✕ボタン）
- 登録した店舗をもとに、**月表示のオリジナルカレンダーを自動生成**。店舗ごとに色分けした
  ドットで、その日にイベントとなる店舗が一目でわかります（前月／翌月／今月に戻るで移動可）
- カレンダーの日付をタップすると、その日に該当する店舗（パターンの説明つき）と、
  その日に保存済みの実戦ログをまとめて表示
- 実戦データ入力の「ホール」欄に登録済みの店舗名を入力（入力候補から選択可）すると、
  その日がルールに一致すれば「イベント日」チェックが自動でON/OFFされる
  （ホールが登録済み店舗と一致しない場合は、手動でのチェックに干渉しません）
- 稼働ログの記録にもホール名が保存され、カレンダー上に「実戦ログを保存した日」として
  マーク表示、「稼働ログ・統計」でホールごとの平均・高設定期待度を比較できます

登録できるのは「日にち・曜日で表現できる規則的なパターン」のみです。「第2日曜日」のような
規則は備考欄への記載にとどまり、自動判定・自動チェックの対象にはなりません。イベント日情報は
各ホールの公式サイトやSNSの告知をもとに手動で登録してください（自動取得はできません）。

## 稼働ログ・統計機能
「この結果をログに保存する」を押すと、日付・台番号（またはメモ）・イベント日フラグと
一緒に判別結果がこの端末に保存されます。「稼働ログ・統計」カードでは、保存した記録を
機種・台番号で絞り込みながら、

- 平均の高設定(4〜6)/低設定(1〜3)期待度
- 曜日別の平均・高設定期待度
- ホール別の平均・高設定期待度（チェーン店ごとの傾向比較）
- イベント日と通常営業日の比較

を集計できます。**これはあなた自身が入力した実戦データから逆算した「推定」の集計**で
あり、ホールが実際にどの設定を投入したかという事実データではありません。母数（n）が
少ない曜日・条件ほど数値は大きく振れるため、傾向として語るには最低でも同条件で
5〜10件以上のデータを集めることを推奨します。記録は1件ずつ削除でき、絞り込み条件に
一致する記録をまとめて削除することもできます。

## 判別ロジック
各設定のBIG確率・REG確率（メーカー公表相当の理論値）をもとに、入力された
「BIG回数・REG回数・ハズレ回数」を多項分布の観測値とみなし、設定1〜6それぞれについて
対数尤度を計算します。得られた尤度を（事前分布を均等と仮定して）正規化し、
「この実戦データが得られたときに各設定である確率」としてベイズ的に提示します。

```
尤度(設定s) ∝ pBIG(s)^BIG回数 × pREG(s)^REG回数 × (1 - pBIG(s) - pREG(s))^ハズレ回数
```

サンプル数（総ゲーム数）が少ないほど推定は大きく揺れます。目安として3000G以上の
データがあると推定の精度が上がります。

## 内蔵機種データについて
アプリには以下8機種の設定1〜6のBIG/REG確率（分母表記）をあらかじめ登録しています。

- マイジャグラーⅤ/Ⅵ
- アイムジャグラーEX/ネオアイムジャグラーEX
- ファンキージャグラー2
- ハッピージャグラーⅤⅢ
- ゴーゴージャグラー3
- ジャグラーガールズSS
- ミスタージャグラー
- ウルトラミラクルジャグラー

これらの数値は、インターネット上に公開されている攻略情報サイトの記載を参考にした
**概算値**であり、正確性を保証するものではありません（機種のバージョン・改訂によって
数値が異なる場合もあります）。実際に判別に使う際は、必ずメーカー公式のスペック表や
ホール設置の説明書などで数値を確認し、アプリ下部の「⚙️ 確率データを編集・追加する」
から正しい値に書き換えてから使ってください。ここにない機種も、同じ画面から
「＋機種追加」で自由に追加できます。

## 対象の絞り込み（平均回転数フィルタ・中小店舗の除外）
マイジャグラー・アイムジャグラー・ゴーゴージャグラーは、設定が入りにくいとされる小規模店舗と
集中投資が期待できる大型店・稼働店を、台データからは機械的に区別できません。そこで店舗ごとに
「平均回転数（参考値）」を登録し、**しきい値（既定2000G）以上の店舗だけを一覧・イベント
カレンダーの対象にする**フィルタを実装しています。

- 「登録済みの店舗」の各店舗に「平均回転数（参考値・任意）」「回転数の出典・取材日など（任意）」
  を入力できます（未入力の店舗はフィルタON時に対象外になります）
- フィルタをONにすると、一覧・イベントカレンダーの表示（ドット・凡例）・候補リストのすべてが
  しきい値以上の店舗だけに絞り込まれます。しきい値は自由に変更できます
- フィルタのON/OFF・しきい値はこの端末に保存され、次回起動時も保持されます

### 平均回転数データの限界（正直な制約）
主要な台データサイト（アナスロ・ペカセン・スロレポ等）は自動取得をブロックしており、
機種別（マイジャグラー/アイムジャグラー/ゴーゴージャグラー個別）の平均回転数を候補すべてに
ついて収集することはできませんでした。内蔵候補136件のうち、**平均回転数データがあるのは
3件のみ**です（[スロパイ(slotana777.com)](https://slotana777.com/)の「取材実績」ページから
取得した**店舗全体**の平均回転数で、機種別の内訳ではありません）:

| 店舗名 | 平均回転数 | 出典 |
|---|---|---|
| マルハン新宿東宝ビル店 | 約5,563G | スロパイ取材実績3回の平均 |
| 楽園蒲田店 | 約2,815G | スロパイ取材実績3回の平均（1,849〜3,597Gとばらつきあり） |
| エスパス日拓西武新宿駅前 | 3,183G | スロパイ取材実績1回 |

残り133件は回転数データ未収集のため、フィルタON時は表示されません。ご自身で確認した数値を
「登録済みの店舗」の✎編集から入力すれば、フィルタの対象に追加できます。

## 注意事項
- 内蔵の「東京都のホール」候補リストは、外部サイト（P-WORLD・アナスロ・みんパチ）掲載情報を
  参照した特定時点のスナップショットです。閉店・移転・データ公開の中止など、
  実際の状況と異なる場合があります。来店前に必ず最新情報をご自身で確認してください。
- みんパチ由来の候補は、台データを自店で公開しているかどうかを確認できていません
  （「自店データ公開」バッジが付くのはP-WORLD・アナスロ由来の候補のみです）。
- 本アプリは統計的な参考情報を提供するものであり、実機の設定を確定・保証するものでは
  ありません。
- 遊技は自己責任・節度を持って行ってください。20歳未満の方の遊技はできません。
- BIG/REGの回数以外の要素（ぶどう確率、コインの増減、ボーナス中の払い出し等）は
  現バージョンでは判別計算に使用していません。
