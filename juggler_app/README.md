# ジャグラー設定判別アプリ

パチスロ「ジャグラーシリーズ」のBIG回数・REG回数・総ゲーム数から、設定1〜6それぞれの
可能性を統計的に推定する、ブラウザだけで動く単一HTMLアプリです。サーバーもビルドも
不要で、`index.html` をダブルクリックして開くだけで使えます（インターネット接続不要）。

## 使い方
1. `index.html` をブラウザ（スマホでもPCでも可）で開く
2. 人気ランキング上位3機種はワンタップの機種選択ボタンから選べる（それ以外はプルダウンから）
3. 総ゲーム数・BIG回数・REG回数を入力して「設定を判別する」を押す
4. 実戦データのまとめと、設定1〜6の推定確率（棒グラフ）が表示される
5. 気に入った結果は「この結果をログに保存する」で記録し、下の「稼働ログ・統計」で
   曜日別・イベント日別などの傾向を集計できる

データはサーバーに送信されません。すべてブラウザ内で完結し、追加・編集した確率データや
保存したログは、その端末の `localStorage` にのみ保存されます。

## 人気ランキング（2026年版・参考）
複数のスロット情報サイトの記事（設置台数・導入率・プレイヤー人気）を突き合わせた
参考ランキングです。アプリはこの上位3機種を優先的に整備しています。

1. マイジャグラーⅤ/Ⅵ
2. アイムジャグラーEX/ネオアイムジャグラーEX
3. ゴーゴージャグラー3
4. ファンキージャグラー2
5. ハッピージャグラーⅤⅢ

店舗や時期によって実際の人気・設置状況は変動するため、あくまで目安です。

## チェーン店・イベント日管理機能
よく行くホール・チェーン店の「毎月◯日」「毎週◯曜日」のイベント日パターンを登録できます。

- 店舗名・毎月のイベント日（カンマ区切りで複数指定可）・毎週のイベント曜日・備考を登録
- 登録した店舗をもとに、**月表示のオリジナルカレンダーを自動生成**。店舗ごとに色分けした
  ドットで、その日にイベントとなる店舗が一目でわかります（前月／翌月／今月に戻るで移動可）
- カレンダーの日付をタップすると、その日に該当する店舗（パターンの説明つき）と、
  その日に保存済みの実戦ログをまとめて表示
- 実戦データ入力の「ホール」欄に登録済みの店舗名を入力（入力候補から選択可）すると、
  その日がルールに一致すれば「イベント日」チェックが自動でON/OFFされる
  （ホールが登録済み店舗と一致しない場合は、手動でのチェックに干渉しません）
- 稼働ログの記録にもホール名が保存され、カレンダー上に「実戦ログを保存した日」として
  マーク表示、「稼働ログ・統計」でホールごとの平均・高設定期待度を比較できます

登録できるのは「日にち・曜日で表現できる規則的なパターン」のみです。「第2日曜日」のような
規則は備考欄への記載にとどまり、自動判定・自動チェックの対象にはなりません。イベント日情報は
各ホールの公式サイトやSNSの告知をもとに手動で登録してください（自動取得はできません）。

## 稼働ログ・統計機能
「この結果をログに保存する」を押すと、日付・台番号（またはメモ）・イベント日フラグと
一緒に判別結果がこの端末に保存されます。「稼働ログ・統計」カードでは、保存した記録を
機種・台番号で絞り込みながら、

- 平均の高設定(4〜6)/低設定(1〜3)期待度
- 曜日別の平均・高設定期待度
- ホール別の平均・高設定期待度（チェーン店ごとの傾向比較）
- イベント日と通常営業日の比較

を集計できます。**これはあなた自身が入力した実戦データから逆算した「推定」の集計**で
あり、ホールが実際にどの設定を投入したかという事実データではありません。母数（n）が
少ない曜日・条件ほど数値は大きく振れるため、傾向として語るには最低でも同条件で
5〜10件以上のデータを集めることを推奨します。記録は1件ずつ削除でき、絞り込み条件に
一致する記録をまとめて削除することもできます。

## 判別ロジック
各設定のBIG確率・REG確率（メーカー公表相当の理論値）をもとに、入力された
「BIG回数・REG回数・ハズレ回数」を多項分布の観測値とみなし、設定1〜6それぞれについて
対数尤度を計算します。得られた尤度を（事前分布を均等と仮定して）正規化し、
「この実戦データが得られたときに各設定である確率」としてベイズ的に提示します。

```
尤度(設定s) ∝ pBIG(s)^BIG回数 × pREG(s)^REG回数 × (1 - pBIG(s) - pREG(s))^ハズレ回数
```

サンプル数（総ゲーム数）が少ないほど推定は大きく揺れます。目安として3000G以上の
データがあると推定の精度が上がります。

## 内蔵機種データについて
アプリには以下8機種の設定1〜6のBIG/REG確率（分母表記）をあらかじめ登録しています。

- マイジャグラーⅤ/Ⅵ
- アイムジャグラーEX/ネオアイムジャグラーEX
- ファンキージャグラー2
- ハッピージャグラーⅤⅢ
- ゴーゴージャグラー3
- ジャグラーガールズSS
- ミスタージャグラー
- ウルトラミラクルジャグラー

これらの数値は、インターネット上に公開されている攻略情報サイトの記載を参考にした
**概算値**であり、正確性を保証するものではありません（機種のバージョン・改訂によって
数値が異なる場合もあります）。実際に判別に使う際は、必ずメーカー公式のスペック表や
ホール設置の説明書などで数値を確認し、アプリ下部の「⚙️ 確率データを編集・追加する」
から正しい値に書き換えてから使ってください。ここにない機種も、同じ画面から
「＋機種追加」で自由に追加できます。

## 注意事項
- 本アプリは統計的な参考情報を提供するものであり、実機の設定を確定・保証するものでは
  ありません。
- 遊技は自己責任・節度を持って行ってください。20歳未満の方の遊技はできません。
- BIG/REGの回数以外の要素（ぶどう確率、コインの増減、ボーナス中の払い出し等）は
  現バージョンでは判別計算に使用していません。
